Автоканал про вузы, поступление и науку

Как работает. Workflow запускается каждые 10 минут, но бот публикует пост, только когда подошло время. Днём примерно раз в 30 минут, ночью (23:00-07:00 по Маврикию) примерно раз в 90 минут, каждый раз со случайным разбросом плюс-минус 25 процентов. Время следующего поста хранится в posted.json.

Выбор поста, когда пришло время:
1. Бот читает все ленты из sources.json и находит новые новости.
2. Дешёвая модель ставит каждой три оценки: важность, польза абитуриенту, срочность. Из них считается рейтинг от 0 до 10 (55 процентов важность, 45 процентов польза).
3. Рейтинг 7 и выше и новость срочная: очередь top, выходит первой, лучшие вперёд. Срочная новость старше 3 дней уходит в запас.
4. Важная, но общая (не привязана ко времени) и средние новости с рейтингом 5-7: запас reserve. Они хранятся 30 дней и публикуются, только когда хороших срочных новостей нет.
5. Рейтинг ниже 5: выбрасывается.
6. Каждый 6-й пост, а также когда новостей нет, это факт о вузе по статье Википедии. К нему берётся главное фото статьи, если у него свободная лицензия, с подписью автора.
7. Пост пишется по-русски только по тексту источника, это перевод и пересказ. Если в посте есть число, которого нет в источнике, пост отклоняется. Внизу ссылка на оригинал.

Модели. Если не заданы, бот сам спрашивает у Groq список доступных вашему ключу моделей и выбирает: основную для постов и дешёвую для оценок. Можно задать вручную переменными LLM_MODEL и LLM_RANK_MODEL.

Секреты (Settings - Secrets and variables - Actions - Secrets): LLM_API_KEY (ключ Groq или другого OpenAI-совместимого API), TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID (адрес канала с собакой). Для платного Claude вместо LLM_API_KEY используйте ANTHROPIC_API_KEY.

Настройки без правки кода (там же, вкладка Variables, все необязательные):
DAY_MINUTES - интервал днём в минутах, по умолчанию 30
NIGHT_MINUTES - интервал ночью, по умолчанию 90
LLM_BASE_URL - адрес другого API, например Gemini: https://generativelanguage.googleapis.com/v1beta/openai
LLM_MODEL, LLM_RANK_MODEL - названия моделей

Ручной запуск (Actions - autopost - Run workflow) публикует пост сразу, не дожидаясь времени.

Важно про лимиты. Для приватного репозитория GitHub даёт 2000 минут Actions в месяц, а этот бот запускается каждые 10 минут. Для бесплатной работы репозиторий должен быть публичным. Секреты при этом остаются скрытыми, но код и posted.json будут видны всем.

Файлы:
sources.json - список вузов и новостные ленты (RSS 2.0, категории admissions и science)
posted.json - память бота: что опубликовано, очередь новостей, время следующего поста. Не удаляйте.
bot.py - сам бот, вверху все настройки.

Проверка без публикации на своём компьютере:
DRY_RUN=1 LLM_API_KEY=ключ python bot.py
Пост напечатается в консоли, ничего не отправится и не запишется.
