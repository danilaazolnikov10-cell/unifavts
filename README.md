Автоканал про вузы, поступление и науку

Каждый день в 10:00 по Маврикию бот публикует один пост в Telegram-канал.

Как выбирается пост. Бот собирает кандидатов трёх типов: факт о вузе (статья Википедии), новость про поступление и международное образование, научная новость. Claude оценивает каждого от 1 до 10 по тому, насколько он зацепит школьника, который хочет учиться за рубежом. Берётся лучший. Если вчера был тот же тип поста, его оценка снижается, чтобы лента не однообразилась. Оценка ИИ это редакторское суждение, а не данные о реальных просмотрах.

Перевод. Источники на английском. Claude пишет пост по-русски: это перевод и пересказ, а не копия.

Фото. К постам-фактам бот берёт главное фото статьи Википедии, но только если лицензия свободная (CC или общественное достояние), и подписывает автора и лицензию. К новостям фото не скачивается: Telegram сам показывает превью со страницы издания.

Защита от выдумок. Claude пересказывает только текст источника. Скрипт отклоняет пост, если в нём есть число, которого нет в источнике. Под каждым постом стоит ссылка на оригинал.

Запуск, один раз:

1. В Telegram откройте @BotFather, команда /newbot, сохраните токен бота.
2. Создайте канал, добавьте бота администратором с правом публиковать сообщения.
3. TELEGRAM_CHAT_ID: для публичного канала это @имя_канала. Для приватного это числовой id вида -100...
4. Ключ ИИ, любой из двух вариантов.
   Бесплатно, Groq: console.groq.com, войти через Google или GitHub, API Keys, Create API Key. Секрет называется LLM_API_KEY. Больше ничего настраивать не надо, по умолчанию бот использует Groq и модель llama-3.3-70b-versatile.
   Бесплатно, Google Gemini: ключ в Google AI Studio. Секрет LLM_API_KEY, и ещё две переменные репозитория (Settings - Secrets and variables - Actions - Variables): LLM_BASE_URL = https://generativelanguage.googleapis.com/v1beta/openai и LLM_MODEL = название flash-модели из документации Google.
   Платно, Claude: console.anthropic.com, секрет ANTHROPIC_API_KEY (а LLM_API_KEY тогда не задавайте). Русский у Claude заметно лучше.
   У бесплатных тарифов жёсткие лимиты на токены в минуту: бот делает паузы между запросами и повторяет запрос при ошибке 429, поэтому один запуск занимает несколько минут. Это нормально.
5. Создайте приватный репозиторий на GitHub и загрузите туда все файлы этой папки.
6. Settings - Secrets and variables - Actions - New repository secret. Добавьте секреты: LLM_API_KEY (или ANTHROPIC_API_KEY, если Claude), TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID.
7. Вкладка Actions - daily-post - Run workflow. Это ручной запуск для проверки. Можно выбрать тип: fact, admissions или science.

Проверка без публикации на своём компьютере:
DRY_RUN=1 LLM_API_KEY=ключ python bot.py   (для Claude вместо LLM_API_KEY используйте ANTHROPIC_API_KEY)
Пост напечатается в консоли, ничего не отправится и не запишется.

Что менять:
sources.json - список вузов (по названию статьи в английской Википедии) и новостные ленты (RSS). Чтобы добавить сайт, добавьте строку с name, url ленты и category: admissions или science. Лента должна быть в формате RSS 2.0. Каждый вуз используется один раз. Когда непоказанных вузов остаётся меньше десяти, бот сам просит Claude предложить новые, проверяет каждое название по Википедии и дописывает подходящие в posted.json. Вручную список пополнять не нужно.
bot.py - вверху константы: сколько вузов участвует в отборе, штраф за повтор типа, модель.
posted.json - память бота о том, что уже опубликовано. Не удаляйте.

Если лента перестала открываться, бот пропустит её и возьмёт кандидатов из остальных.
